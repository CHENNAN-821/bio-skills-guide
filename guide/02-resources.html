LESSON 02 / 14

选择合适的技能库

看懂五个技能库的用途、区别和维护状态。

约 10 分钟阅读资料核对 2026-11-13

五个技能库各有什么用#

下面是技能资源的统一导航。优先选择覆盖当前问题、说明清楚的项目；不必因为技能数量多，就把整套全部装上。

资源适合做什么阅读提示
R1 K-Dense通用科研与生信工具指南，适合先装少量技能英文为主；有安装、示例、参考资料和视频。
R2 OmicVerse Skills单细胞、bulk 和空间转录组等组学分析README 为中文；分析与 OmicVerse 生态关系较紧。
R3 SciAgent-Skills生信、统计、药物发现和科研写作等技能按领域分组，附集成模板和操作示例。
R4 ssinder 技能库RNA-seq、单细胞、结构分析和文献检索部分说明为中文，提供脚本和方法资料。
R5 GPTomics bioSkills序列、差异表达、变异分析等参考资料已于 2026 年 8 月 15 日归档，后续适配需自己核对。

如何做出选择#

  • 只想先学会使用一个 Skill：从 R1 的 biopython 开始。
  • 已明确做单细胞或转录组：先读 R2，再对照课程理解流程。
  • 已有较多科研任务：再考虑 R3 或其他专题库。
  • 学习脚本实现：可以参考 R4；正式统计分析优先采用成熟工具并验证结果。

维护状态怎么判断 看仓库是否有 Archived 提示、最近提交、Issues 中的问题及依赖说明。Star 数量不能替代方法和代码检查。

来源说明 这些技能库是第三方项目。Codex 与 Claude Code 的宿主官方操作文档单独列在 T5 和 T6。

参考资料：R1 · R5

K Dense 从一个技能开始#

K-Dense 的 Scientific Agent Skills 是综合科研技能集合，旧链接 claude-scientific-skills 会跳转到现仓库。生信只是其中一部分。建议先打开具体技能目录，确认用途与依赖。

打开 K-Dense 仓库

技能名用途开始前要知道
biopython序列读写、格式转换和序列统计本教程的第一次练习用它。
scanpy单细胞质控、降维、聚类和探索性 marker 分析确认表达矩阵来源，不能把所有细胞当独立样本。
pydeseq2bulk RNA-seq 的差异表达分析需要适用的计数数据、独立生物学重复和样本信息。
anndata理解和读写单细胞数据对象主要解决数据结构与格式问题，不等于完整分析。

读懂一个技能文件夹#

TEXT
skills/biopython/
  SKILL.md       核心操作指南
  references/    详细说明与参考资料

先看 SKILL.md 的 description、compatibility 和安装说明，再看与你当前任务有关的示例。依赖以具体技能为准，不要用仓库开发环境替代全部分析依赖。

可以直接发给 AI 的第一句话#

“请先阅读 biopython 技能，说明它能做什么、需要什么环境，再检查我当前的 Python。暂时只检查，不下载大型数据，不运行完整组学流程。”

查看作者提供的任务示例

参考资料：R1 · T1 · T4

OmicVerse 按组学流程找技能#

OmicVerse Skills 的中文首页适合先了解“某一步应该用什么方法”。它覆盖数据读入、单细胞预处理、批次整合、细胞注释、差异表达和富集等环节。

打开 OmicVerse Skills 仓库

需求在目录中查找
第一次读入数据data-io-loading datasets-loading
单细胞预处理single-cell-preprocessing
批次整合与细胞注释single-cell-batch-integration single-cell-annotation
bulk 差异表达bulk-deg-analysis bulk-deseq2-analysis
通路与共表达网络gsea-enrichment bulk-wgcna-analysis
空间转录组spatial-tutorials

两种使用思路#

使用 OmicVerse Agent：仓库给出 pip install omicverse-skills 的安装方式，由配套 Agent 查找技能。仍需另外配置 OmicVerse、分析依赖及所用模型的访问方式。

使用其他 AI 编程助手：进入 src/omicverse_skills/skills/，挑一个具体技能目录，让助手按其 SKILL.md 阅读和操作。主文件夹的名称与技能内声明的 name 可能不同，调用前以文件内容为准。

先验证能读技能 再验证能分析#

第一步确认技能被找到，第二步确认 import omicverse 能成功，第三步才用小数据验证函数。只装 omicverse-skills，不代表所有分析软件已经安装。

中文首页便于选路，但具体技能和参考资料中仍有英文。让 AI 翻译并解释参数时，保留原始函数名和参数名。

参考资料：R2 · T7

其他技能库怎样搭配使用#

SciAgent Skills 用于跨任务查找#

它将技能按生信、结构生物学、统计、科研写作等分类组织。每个技能通常包含适用场景、快速开始、参数和排错信息。适合已有明确问题时按名称检索。

打开 SciAgent-Skills

新手操作：先在 README 找任务示例，再进入对应技能目录阅读。使用其集成模板时，把需要的内容合并进已有配置；不要直接覆盖自己的 AGENTS.md 或 CLAUDE.md。

ssinder 技能库 用于学习完整流程#

提供 bulk RNA-seq、单细胞、蛋白结构、文献检索和科研绘图等技能，部分操作说明为中文，并附脚本与方法资料。

打开 bioinformatics-agent-skills

特别留意：bulk-rnaseq 同时提供自实现的 Python 统计后端和调用 R DESeq2 的后端。相似的输出列名不代表算法与数值完全等价；正式差异分析应确认后端并做方法复核。

GPTomics bioSkills 用作扩展参考#

覆盖序列、比对、变异、差异表达等方向，有类别说明和安装脚本。仓库目前已归档，内容可用于学习，旧命令、依赖和宿主兼容性需要重新检查。

打开 GPTomics bioSkills

选库原则 先把一套小流程跑通，再补充缺少的能力。多个仓库可能包含同名技能，安装前先看已有目录，避免混淆来源。

参考资料：R3 · R5 · T8
