LESSON 07 / 14

准备独立练习环境

按你的操作系统安装练习需要的软件包。

约 5 分钟阅读资料核对 2026-11-13

已经有 Python 的读者从这里继续。独立环境像一个专用工具箱：本次练习需要的包放在里面，其他项目的包保持各自管理。

Windows PowerShell 示例#

在 bio-skills-demo 文件夹中打开终端，先确认当前路径，再逐条执行。已存在 .venv 时先确认它属于本项目，避免覆盖。

TEXT
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install biopython
.\.venv\Scripts\python.exe -c "import sys, Bio; print(sys.executable); print(Bio.__version__)"

说明 本例直接指定环境中的 python.exe，不需要先激活环境，也不需要修改 PowerShell 的执行策略。安装成功时应显示解释器路径和 Biopython 版本。

macOS 或 Linux 示例#

TEXT
python3 -m venv .venv
.venv/bin/python -m pip install biopython
.venv/bin/python -c "import Bio; print(Bio.__version__)"

现有环境如何复用#

若你已有专用于生信学习的环境，可直接使用它，但应让 AI 记录解释器路径和包版本。本教程主线的 Biopython 练习不要求同时装好 Scanpy、R 或所有技能依赖。

软件版本 本次核对的 K-Dense Biopython 技能要求 Python 3.10 及以上，并注明其使用的测试版本。多个科学软件的兼容范围不同，正式复现应按具体 Skill 锁定并记录版本。

如果 pip 报错，先保存完整报错、Python 版本和路径，再按常见问题章节排查。不要把所有升级命令一起运行。
