LESSON 04 / 14

检查已有的 Python

确认版本、解释器和 pip，复用你已有的环境。

约 5 分钟阅读资料核对 2026-11-13

如果电脑已经有 Python，不要急着再安装一份。先确认 AI 助手真正使用哪个解释器、版本是否满足所选技能要求，以及依赖会安装到哪里。

在终端中逐条运行#

TEXT
python --version
python -c "import sys; print(sys.executable)"
python -m pip --version

你应看到 Python 版本、解释器路径和 pip 路径。若 Windows 的 python 命令不可用，但装有启动器，可尝试 py --version；之后由你或 AI 使用实际可用的命令。

不同读者怎样继续#

现有情况下一步
已有可用 Python按独立练习环境章节为练习创建独立环境。原有环境不需要删除。
已有 Conda 环境可以在明确的专用环境中练习，先确认解释器路径和包版本。
尚未安装 Python从 python.org 下载适合系统的版本，完成后重新打开终端再检查。
准备做大量 FASTQ 分析根据上游工具要求使用 Linux、WSL2 或服务器；不要把 Linux 命令原样贴进 PowerShell。

最低准备清单#

  • 使用 Skills 时，需要可正常对话并读写项目文件的 AI 编程助手；只跟练 Python 示例，可以先不用 AI。
  • 一个专用练习文件夹，以及可用的 Python。
  • 需要下载依赖时具备相应网络访问；先用 CPU 和小数据即可。

本教程的 FASTA 练习可在 Windows 原生 Python 中完成。K-Dense 仓库整体将 Windows 配合 WSL2 列为运行平台之一，其他生信流程应分别核对要求。

费用区分 公开仓库可以阅读，不代表 AI 模型、API、数据库或云算力都免费。开始任务前先确认是否使用付费服务。
