LESSON 03 / 14

读懂和下载 GitHub 项目

从 README 找到安装要求，下载完整技能文件夹。

约 5 分钟阅读资料核对 2026-11-13

1 打开项目首页

从文末链接进入，确认地址中的作者名和仓库名与手册一致。不要从不明转载站下载替代安装包。

2 先读 README

优先找到 Requirements、Installation、Usage、Examples 和 Troubleshooting，分别对应要求、安装、用法、示例和排错。

3 打开具体技能

K-Dense 的技能位于 skills/；OmicVerse 位于 src/omicverse_skills/skills/。点进某个目录，应能看到 SKILL.md。

4 下载项目压缩包

在电脑浏览器中点击 Code，再选 Download ZIP。下载后使用“全部解压缩”，得到真正的文件夹。不要在压缩包预览窗口里直接使用。

5 复制完整的技能文件夹

连同 references、scripts 等子目录一起复制，保留原有结构。只复制 SKILL.md 可能丢失脚本和说明。

6 记录来源与版本

写下仓库网址、下载日期、版本标签或提交编号。遇到问题时，别人才能知道你使用的是哪一份内容。

这几个按钮分别是什么意思#

页面位置作用
Code浏览代码、复制仓库地址、下载 ZIP。
Releases作者发布的版本；并非每个仓库都有。
Issues查看和提交问题，先搜别人是否遇到同样报错。
LICENSE查看复制、修改或再分发时应遵守的许可。
Archived仓库已归档，通常不再接受常规更新。

说明 GitHub 网页布局可能调整，以上描述的是按钮用途，不依赖固定截图位置。
