第一次练习 读取三条 DNA 序列#

目标：读取一个 FASTA 文件，统计每条 DNA 的长度与 GC 比例，输出 CSV 表。三条序列是人为编写的教学样例，不代表真实实验或生物学发现。

步骤一 准备输入文件#

在项目中创建 data 文件夹，用纯文本编辑器新建 demo.fasta，内容如下。注意保留大于号，文件不要被保存成 demo.fasta.txt。

FASTA
>demo_a
ATGCGCATATGC
>demo_b
ATATATATATAT
>demo_c
GCGCGCGCGCGC

FASTA 规则 以 > 开头的是序列名称，后面是序列内容。文件可以有多条序列；本练习仅使用 A、T、G、C。

步骤二 把任务交给 AI#

“请读取 biopython 技能，用本项目的 .venv 解释器处理 data/demo.fasta。逐条统计序列名称、长度和 GC 百分比，保留两位小数，输出 results/sequence_summary.csv。保留输入，保存脚本和环境版本；不要调用在线数据库。完成后与手算结果核对。”

步骤三 用这张表核对结果#

序列名称长度GC 百分比
demo_a1250.00
demo_b120.00
demo_c12100.00

GC 百分比 = G 与 C 的数量之和 ÷ 序列总长度 × 100。本例只含四种标准碱基；真实数据若有 N 等模糊碱基，应先说明分母与处理规则。

第一次练习 运行并保存结果#

也可以直接使用配套 ZIP 中的 first_fasta.py。把它与 data 文件夹放在同一个项目目录，先按独立练习环境章节安装 Biopython，再执行。

PYTHON
from pathlib import Path
import csv
from Bio import SeqIO
from Bio.SeqUtils import gc_fraction
 
root = Path(__file__).resolve().parent
source = root / "data" / "demo.fasta"
output = root / "results" / "sequence_summary.csv"
rows = []
for record in SeqIO.parse(source, "fasta"):
    sequence = str(record.seq).upper()
    if not sequence or set(sequence) - set("ATGC"):
        raise ValueError(f"Invalid demo sequence: {record.id}")
    rows.append([record.id, len(sequence),
                 f"{gc_fraction(sequence) * 100:.2f}"])
if not rows:
    raise ValueError("No FASTA records found")
output.parent.mkdir(parents=True, exist_ok=True)
with output.open("w", newline="", encoding="utf-8-sig") as f:
    writer = csv.writer(f)
    writer.writerow(["sequence_id", "length", "gc_percent"])
    writer.writerows(rows)
print(output)

运行命令#

TEXT
.\.venv\Scripts\python.exe first_fasta.py

macOS 或 Linux 把解释器部分换成 .venv/bin/python。终端应打印结果文件路径，打开 CSV 后应与练习中的预期结果表的三行数值一致。

完成标志 输入文件保留、脚本可再次运行、CSV 数值正确、解释器与包版本有记录。你已经完成一次“输入 → 执行 → 输出 → 核验”。

示例验证 配套脚本已用 Python 3.12 与 Biopython 1.88 试跑，三条结果与手算一致。
