LESSON 13 / 14

复制即用的提问模板

把任务、数据、环境与核验要求说清楚。

约 4 分钟阅读资料核对 2026-11-13

模板一 先认识资源#

我刚接触生信。请阅读这个 GitHub 仓库的 README 和与任务相关的 SKILL.md，用中文解释它能解决什么问题、需要哪些数据与软件、哪些步骤可以先跳过。先给学习顺序，不运行分析。仓库链接：填写这里。

模板二 检查我已有的 Python#

我已经有 Python。请检查当前可用的解释器、版本、pip 对应位置及本任务所需的包，说明是否满足所选 Skill。已有环境优先核对；如需额外依赖，使用独立环境，先列出拟运行命令和写入位置。不要改动其他项目。

模板三 执行一个小分析#

我的目标：填写问题。输入：填写路径、格式、数据来源和处理历史。样本：填写物种、分组、重复和批次。请读取对应技能，先检查输入与方法是否适用，再用小数据验证。保留原始输入，输出脚本、表格、图、版本与运行日志，并告诉我每项结果怎样核对。

模板四 解决一个具体报错#

我在做：填写任务。系统与环境：填写操作系统、解释器路径和软件版本。实际命令：粘贴原命令。完整报错：粘贴文本。请先解释报错含义，定位最可能失败的一步，给出最小修复方案，并说明如何验证。不要直接重装全部环境。

模板五 审核已有结果#

请根据现有代码、日志和输入来源，核对矩阵方向、样本匹配、对照方向、模型假设和诊断结果。区分已验证的事实、需要补充的信息和暂不能得出的结论。不要为了图形好看而改变分析标准。

替换提示 把“填写这里”替换成你的真实任务信息。敏感内容先脱敏，未知信息明确写“不知道”，不要编造。
