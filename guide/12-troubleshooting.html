LESSON 12 / 14

遇到报错怎样排查

按环境、路径、输入和方法逐步定位问题。

约 5 分钟阅读资料核对 2026-11-13
现象优先检查和处理
找不到技能检查是否解压、是否放在宿主实际读取的目录、技能目录中是否直接包含 SKILL.md。
ModuleNotFoundError用实际运行脚本的解释器执行 -m pip show 包名，确认包安装在同一个环境。
python 或 pip 不可用先确认现有解释器路径；重新打开终端。不要反复安装多套 Python 来碰运气。
找不到输入文件核对路径、当前目录、扩展名和文件是否解压；路径有空格时给命令参数加引号。
Linux 命令在 Windows 失败确认命令属于 PowerShell 还是 Bash；使用对应终端或请 AI 改写。
下载或 API 访问失败检查目标地址、网络、权限与请求限制；服务密钥不等于公开下载链接。
内存不足或运行很久先用小数据或抽样验证；记录数据规模，再评估所需内存、CPU 或服务器。
结果异常或没有显著基因先查输入类型、样本匹配、模型、过滤和统计功效；不靠随意改阈值追求显著。

向别人求助时一次发齐#

任务目标、操作系统、Python/R 版本、解释器路径、实际命令、完整报错、脱敏后的最小输入示例，以及你预期看到的结果。

处理顺序 保存报错 → 确定失败的那一步 → 核对环境与输入 → 一次只修改一个相关因素 → 用小数据重跑。

不要公开 API Key、密码、个人信息和未经授权的研究数据。日志与截图发送前也要检查；本地运行脚本不代表 AI 对话内容不会传给模型服务，应另查产品的数据处理说明。
