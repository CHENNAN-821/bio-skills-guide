开始前，你可能想问。

更多常见问题
没有生信基础，也能开始吗？

可以从基础概念和三条短序列练习开始。真正处理课题数据时，再补充生物学、统计和实验设计知识。

已经有 Python，还要再安装一遍吗？

先检查现有解释器和版本，满足所选技能要求时可继续使用。练习依赖放在独立环境里，便于与其他项目分开管理。

网站可以直接运行 RNA-seq 或单细胞分析吗？

网站提供教程与小型 GC 统计练习。完整组学分析仍在你自己的 Python、R、Linux 或服务器环境中进行。

手机可以看教程和下载资料吗？

页面支持手机阅读，资料可以下载保存。终端命令与 Python 脚本更适合在电脑上操作。外部 GitHub 等资源的可访问性取决于实际网络。
